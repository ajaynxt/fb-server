100% Working Facebook Cookie Guide

💻 Method 1: PC / Laptop (Cookie-Editor Extension)

  1. Chrome me Cookie-Editor install karein.
  2. facebook.com par login karein.
  3. Extension open karke Export -> Export as JSON karein.
  4. Copy hua JSON yahan paste karke "Save to Server" daba dein!

📱 Method 2: Mobile Phone (Android)

  1. Play Store se Kiwi Browser download karein.
  2. Kiwi me Cookie-Editor install karke Facebook login karein aur JSON export karein.

🔑 4 Zaroori Cookies:

c_user (UID), xs (Session Token), datr, sb.

Tip: Cookie export karne ke baad Facebook ko browser me Log Out mat karein!
